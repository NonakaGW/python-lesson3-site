01

基本問題 · if

HPが減ったら警告！

約5分

HPが 30より小さい ときだけ「ピンチ！」と表示しよう。

作るプログラムの条件

  1. 変数 hp に 20 を入れる
  2. if を使って、30より小さいときに表示する
実行結果の例（hp = 20）
ピンチ！
できたら試そう

hp = 50 に変えると、何が表示されるかな？

ヒント①　使う記号を思い出そう

「より小さい」を調べるには < を使うよ。

ヒント②　ifの書き方を確認しよう
if hp < 30:
    print("ピンチ！")

この前に hp の変数を作ろう。条件に当てはまらないときは、何も表示されなくてOK。

02

基本問題 · if / else

アイテムを購入しよう

約7分

持っているコインの枚数によって、メッセージを変えよう。

作るプログラムの条件

  1. 変数 coin に 80 を入れる
  2. 100枚以上なら「購入できます！」と表示する
  3. それ以外なら「コインが足りません！」と表示する
実行結果の例（coin = 80）
コインが足りません！
できたら試そう

coin を 100、120 に変えてみよう。

ヒント①　「100以上」はどう書く？

「以上」は >= だよ。100ちょうども含まれるね。

ヒント②　条件分岐の形を確認しよう
if coin >= 100:
    print("購入できます！")
else:
    print("コインが足りません！")

一番上に変数 coin を作ろう。

03

基本問題 · if / elif / else

スコアをランク判定！

約8分

ゲームのスコアに合わせて 3種類のランク を表示しよう。

作るプログラムの条件

変数 score に 75 を入れ、次のルールで判定する。

スコア表示する文字
90以上Sランク
60以上90未満Aランク
60未満Bランク
実行結果の例（score = 75）
Aランク
できたら試そう

score を 95 と 30 に変えて、3つの結果を確認しよう。

ヒント①　条件の順番が大事！

90以上を先に判定すれば、次は60以上かどうかを調べるだけでOK。

ヒント②　elifを使う場所は？
if score >= 90:
    print("Sランク")
elif score >= 60:
    print("Aランク")
else:
    print("Bランク")

この前に score の変数を作ろう。

04

基本問題 · random

サイコロを作ろう！

約7分

実行するたびに 1〜6の数字 がランダムに表示されるプログラムを作ろう。

作るプログラムの条件

  1. import random を書く
  2. random.randint() を使い、変数 dice に入れる
  3. print() で dice を表示する
実行結果の例
4
※1〜6のどれかが表示されるよ。
できたら試そう

何度も実行してみよう。1〜6以外の数字は出ていないかな？

ヒント①　乱数を作る関数は？

random.randint(最小の数, 最大の数) の形で書くよ。

ヒント②　変数に数字を入れるには？
dice = random.randint(1, 6)

この行の前に import random を書き、その後で print(dice) を書こう。

約12分

ここまでに学んだ random × 条件分岐 を組み合わせて、宝箱の種類が決まるプログラムを作ろう。

作るプログラムの条件

random.randint(1, 3) で数字を1つ選び、その数字によって宝箱を表示する。

数字表示する文字
1金の宝箱！
2銀の宝箱！
3銅の宝箱！
実行結果の例
金の宝箱！
※実行するたびに結果が変わることがあるよ。
スタート用コードを見る（必要な人だけ）

まずはここから始めてもOK。続きを自分で書いてみよう！

import random

item = random.randint(1, 3)

# ここから条件分岐を書こう
ヒント①　どの条件から調べる？

if item == 1: から書いてみよう。

ヒント②　残り2つの結果を作るには？

elif item == 2: で銀の宝箱。それ以外は else: で銅の宝箱を表示できるよ。

できたら試そう

何度も実行して、金・銀・銅の宝箱を出してみよう！
